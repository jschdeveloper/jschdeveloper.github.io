Quiz Reni Publicador

Herramienta privada de publicación para el canal de YouTube Quiz Reni.

Qué es

Quiz Reni Publicador es una herramienta privada que usa exclusivamente el propietario del canal de YouTube Quiz Reni. Sirve para publicar en su propio canal los vídeos que genera en su equipo. Antes de cada publicación, el propietario revisa el título, la descripción y la portada.

La herramienta no está disponible para terceros y nadie más la utiliza.

Uso de YouTube API Services

Quiz Reni Publicador usa YouTube API Services únicamente para:

  • subir vídeos al canal del propietario;
  • establecer la portada (miniatura) de esos vídeos;
  • mostrar el nombre del canal conectado.
